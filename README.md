# Estudos e Exercícios em Python

Repositório com exercícios e atividades práticas desenvolvidos durante meus estudos de Python. Reúne exemplos feitos em aula e práticas para reforçar os conceitos da linguagem.

## Conteúdos praticados

- **Fundamentos:** variáveis, condições, laços de repetição e funções.
- **Programação orientada a objetos:** classes, objetos e métodos.
- **Tratamento de erros:** exceções e validações.
- **Manipulação de arquivos:** leitura, escrita, criação de pastas e arquivos CSV.
- **Threads:** execução paralela, sincronização, locks e filas.
- **Processos:** monitoramento de CPU, memória e processos do sistema.
- **Lógica de programação:** resolução de exercícios e pequenos algoritmos.

## Organização

- `Aulas Básicas/` — exemplos dos principais conceitos de Python.
- `Exercicios_Basicos/` — exercícios de lógica e programação.
- `Arquivos/` — atividades de manipulação de arquivos, pastas e dados.
- `Threads/` — exemplos de execução com threads.
- `Exercicios_Threads/` — exercícios práticos de concorrência.
- `processos/` — atividades de monitoramento de processos do sistema.

## Tecnologias

- Python 3
- Biblioteca `threading`
- Biblioteca `psutil`
- Biblioteca `csv`
- Bibliotecas nativas de manipulação de arquivos

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/IsabelLopes04/python.git
   ```
2. Abra a pasta do projeto no VS Code.
3. Escolha o arquivo `.py` que deseja executar.
4. Execute pelo terminal:
   ```bash
   python caminho/do/arquivo.py
   ```

Para executar os exercícios de monitoramento de processos, instale a dependência:

```bash
python -m pip install psutil
```
